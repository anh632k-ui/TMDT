# TMDT – Website bán văn phòng phẩm trực tuyến

Đồ án cuối kỳ Thương mại điện tử. Công nghệ: ASP.NET Core MVC (.NET 8), SQL Server, Entity Framework Core và ASP.NET Core Identity.

- TV2: giao diện phía khách (`Views`, `ViewModels`, `wwwroot/css`, `wwwroot/js`).
- TV3: Models, DbContext, migrations, services và controller phía khách.
- TV4: `Areas/Admin`, `PaymentController`, `Views/Payment`, `Data/DbSeeder.cs`, bảng kiểm thử và kịch bản demo.

Thực hiện trên nhánh riêng và mở Pull Request; không commit trực tiếp `main` sau khi khởi tạo.
